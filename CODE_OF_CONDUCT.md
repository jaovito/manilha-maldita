# Community conduct

Be respectful, constructive and considerate. Discuss code and ideas without personal attacks. Harassment, discrimination, threats, doxxing and deliberately publishing private information are not acceptable.

Keep issues and PRs focused on the project. Give actionable feedback, accept maintainer scope decisions and avoid spam or repeated demands. Respect attribution and other contributors' time.

The maintainer may edit or remove abusive content, close disruptive discussions and restrict participation. Use GitHub's Report abuse controls for harmful public content. Security vulnerabilities belong in the private channel described in [SECURITY.md](SECURITY.md); never disclose private information to report an incident publicly.
