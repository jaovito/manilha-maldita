# Security policy

## Supported code

Security fixes target the latest `main` branch. Historical commits and unsupported deployments do not receive a separate maintenance guarantee.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/jaovito/manilha-maldita/security/advisories/new). Provide affected versions, impact and a minimal reproduction using synthetic data. Do not post exploit details, credentials, session cookies, recovery codes or real player information in public issues or PRs.

Do not test against other players or hosted services without explicit authorization. Local reproduction instructions are in [README.md](README.md); the development security contract is in [docs/security.md](docs/security.md).

The maintainer will assess the report and coordinate fixes and disclosure. There is no guaranteed response time or bug-bounty program. Do not create a public issue merely to request status on a private report.
